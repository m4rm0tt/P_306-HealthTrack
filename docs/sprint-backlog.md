## Definition of Done
Quand considérez-vous une tâche comme terminée ?
- Tous les critères d'acceptation de la User Story sont satisfaits
- Le code est revu et approuvé par un autre membre de l'équipe
- Les tests ont été réalisés et sont concluants
- La fonctionnalité est démontrée et validée par le Product Owner
